# hermes-federated-search

Federated web search backend plugin for
[Hermes Agent](https://github.com/NousResearch/hermes-agent): aggregates
results from multiple search backends (Tavily, SearXNG, custom HTTP
endpoints, ...) and ranks the merged set by relevance.

Provider name: `federated` — selected with `web.search_backend: federated`.

> Status: v1 implementation lands on `feat/federated-search-v1`.
